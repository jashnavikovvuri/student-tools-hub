# 🎓 Student Tools Hub

A modern student-focused web application that brings **AI tools, productivity tools, academic utilities, interview preparation, and project resources** together in one platform.

The goal of Student Tools Hub is to provide students with a single place where they can manage their studies, improve their skills, prepare for placements, and discover project ideas.

---

## 🚀 Live Demo

🔗 **Live Website:** https://student-tools-hub-mu.vercel.app/

---

## ✨ Features

### 🤖 AI & Learning Tools

* 📝 **AI Notes** — Generate and organize study notes
* 🧠 **AI Quiz** — Practice with AI-generated quizzes
* 📄 **Resume Analyzer** — Analyze and improve resumes
* 💻 **AI Code Helper** — Get programming assistance
* 🎤 **Interview Prep** — Prepare for technical interviews

### 📚 Study & Productivity

* 📅 **Study Planner** — Plan and organize study schedules
* ⏱️ **Pomodoro** — Improve focus using Pomodoro sessions
* 🗂️ **Flashcards** — Create and review flashcards
* 📊 **CGPA Calculator** — Calculate academic CGPA
* 📌 **Student Dashboard** — Access tools from one place

### 🚀 Project Section

Students can explore different project ideas and project details.

#### 🤖 AI Project Bot

The AI Project Bot recommends **multiple project ideas** based on:

* Student stream
* Project level
* Preferred technology
* Project type
* Student's own project idea

It can suggest several relevant projects instead of giving only one recommendation.

## 🎯 Main Highlights

### Student Dashboard

The dashboard provides quick access to important academic, AI and productivity tools.

### AI Project Bot

Students can select their:

```text
Stream
   ↓
Project Level
   ↓
Preferred Technology
   ↓
Project Type
   ↓
Optional Project Idea
```

The system then generates a collection of suitable project suggestions.

### Project Suggestions

Each suggested project includes:

* 📌 Project title
* 📝 Project description
* 🚀 Key features
* 🛠️ Technologies
* 🎯 Difficulty level
* 📚 Project type

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd student-tools-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run locally using the Vite development server.

---

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
